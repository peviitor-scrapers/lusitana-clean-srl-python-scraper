# Contributing

Contributions are welcome! Please follow the [peviitor.ro scraper documentation](https://github.com/peviitor-ro/scraper-doc):

1. Keep the scraper GDPR-compliant (title + canonical job URL + optional non-personal fields only).
2. Run `pytest -v` before opening a pull request.
3. Verify changes with `python -m scraper.index --dry-run` before pushing live data.
